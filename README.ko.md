이 절에는 과거 테스트 화면과 분석을 담았습니다. 여섯 이미지에 표시된 테스트 날짜는 모두 **2026-05-25**이며, 이번에 새로 측정하거나 실시간으로 모니터링한 결과가 아닙니다. 실제 성능은 지역, 통신사, 시간대, 노드에 따라 달라집니다. 이미지의 원래 표기를 유지하고 주요 결과를 한국어로 설명합니다.

## Mojie 사이트가 열리지 않을 때

| 발생한 현상 | 먼저 확인할 사항 | 판단할 수 있는 내용 |
| --- | --- | --- |
| 페이지 시간 초과 또는 DNS 오류 | 도메인과 시각을 기록하고 다른 사이트가 열리는지 확인 | 현재 환경에서 접속하지 못한 것이며 서비스 종료를 단정할 수 없음 |
| 인증서 또는 안전하지 않은 연결 경고 | 계정 정보 입력을 멈추고 도메인과 기기 시각을 확인 | 인증서나 연결 문제를 해결한 뒤 로그인해야 하며 경고를 무시해서는 안 됨 |
| 페이지는 열리지만 기존 계정을 사용할 수 없음 | 입력한 계정 정보, 로그인 페이지, 오류를 확인하고 계정 페이지의 지원 채널에 문의 | 웹사이트 접속과 계정 로그인은 별도의 단계 |
| 사이트는 정상이나 클라이언트가 작동하지 않음 | 구독 유효성, 남은 데이터, 클라이언트 설정 확인 | 사이트와 프록시 노드 연결은 따로 점검해야 함 |
| 페이지마다 요금이나 조건이 다름 | 계정 페이지에서 현재 요금제, 유효 기간, 지원 조건 확인 | 구매 또는 갱신 전에 현재 조건을 확인해야 함 |

문제를 알릴 때는 도메인, 베이징 시간 기준 발생 시각, 수행한 단계, 오류 메시지, 최종 페이지 주소를 제공하세요. 비밀번호, 결제 정보, 구독 URL은 공개하지 마세요.

## 요금제와 클라이언트 확인 사항

계정 페이지에서 다음 항목을 비교하세요.

- **과금과 데이터:** 월정액인지 사용량 기준인지, 데이터 만료일이 있는지, 잔액 충전과 요금제 구매가 별도 작업인지 확인합니다.
- **기기 제한:** 허용 기기 수 또는 동시 연결 수와 본인의 휴대전화, 컴퓨터, 클라이언트 지원 여부를 확인합니다.
- **사용 성능:** 환경 설명이 없는 속도 이미지보다 같은 지역, 통신사, 시간대의 실제 결과가 더 유용합니다.
- **고객 지원:** 지원 채널, 환불 조건, 장애 알림 방식을 확인합니다.

확인 가능한 서비스 안내나 클라이언트 자체의 공식 배포 경로에서 소프트웨어를 받으세요. 구독 URL에는 개인 인증 정보가 포함될 수 있으므로 공개 Issue나 스크린샷에 넣지 마세요.

## 자주 묻는 질문

### 최신 Mojie 공식 사이트 주소는 어디에서 확인하나요?

위 주소 목록을 확인하세요. 주소 업데이트 날짜는 문서 상단에 표시되어 있습니다. 링크를 열거나 접속 안내 페이지를 북마크할 수 있습니다. 특정 도메인이 일시적으로 열리지 않으면 다른 주소를 시도하세요.

### 기존 계정으로 로그인하거나 도움을 받으려면 어떻게 하나요?

사이트에 접속해 로그인 메뉴를 선택하고 기존 계정을 사용하세요. 오류가 나면 메시지, 도메인, 발생 시각을 기록해 계정 페이지의 지원 채널에 문의하세요. 공개 Issue에 비밀번호, 결제 정보, 구독 URL을 보내지 마세요.

### 사이트 주소, 구독 URL, 노드는 어떻게 다른가요?

사이트 주소는 서비스 정보를 보거나 계정을 관리하는 데 사용합니다. 구독 URL은 클라이언트가 설정을 가져오는 데 쓰이며 개인 키가 포함될 수 있습니다. 노드는 클라이언트가 실제로 연결하는 네트워크 서비스입니다. 웹사이트가 정상이라고 해서 노드가 작동하거나 속도 테스트가 완료되었다는 뜻은 아닙니다.

### 여러 도메인이 독립적인 예비 경로를 보장하나요?

아니요. 한 도메인에 접속할 수 없을 때 다른 주소를 시도할 수 있지만 같은 사이트로 연결될 수 있습니다. 서로 독립적이거나 다른 노드 또는 더 빠른 프록시 경로임을 보장하지 않습니다.

### Mojie 요금제 가격과 할인 행사는 어디에서 보나요?

계정 페이지에서 현재 요금제, 가격, 행사 조건을 확인하세요. 구매 전 데이터 유효 기간, 기기 제한, 환불 조건을 살펴보고 갱신 전에도 조건 변경 여부를 확인하세요. 실제 성능은 지역, 통신사, 시간대에 따라서도 달라집니다.

### 주소 업데이트 날짜는 자동으로 바뀌나요?

아니요. 주소 목록을 갱신할 때 변경합니다. 일반 문구를 수정하거나 페이지를 다시 생성하는 작업만으로는 자동 변경되지 않습니다.

## 업데이트와 의견 보내기

실제 변경 사항은 이 저장소의 커밋 기록에서 확인할 수 있습니다. 연결되지 않는 주소, 설명과 다른 연결 대상, 문서 오류는 Issue나 수정 제안으로 알려 주세요. 계정, 요금제, 결제 문제는 계정 페이지의 지원 채널을 이용하고 공개 문의에 개인 인증 정보를 포함하지 마세요.
