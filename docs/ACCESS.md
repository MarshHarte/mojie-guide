# 魔戒访问与故障判断指南

## 先区分三个环节

| 环节 | 作用 | 出错时优先检查 |
| --- | --- | --- |
| 网站入口 | 浏览说明、管理账户 | 域名、HTTPS、页面品牌、最终跳转 |
| 订阅链接 | 为客户端提供配置，可能含个人密钥 | 链接是否有效、是否泄露或被重置 |
| 客户端节点 | 实际网络连接 | 当前订阅、流量、节点状态、客户端版本 |

不要把“网页返回 HTTP 200”写成“节点在线”“高速稳定”或“套餐可用”。这些结论需要不同的检查方式。

## 地址无法打开

1. 记录正在访问的完整域名、北京时间和浏览器显示的错误。报告中删除账号标识、邀请码或敏感查询参数。
2. 检查自己常用的其他网页能否访问，以区分单个站点问题与本地网络问题。
3. 如果出现证书警告，停止输入账号和密码，先核对拼写、设备时间和站点身份。不要忽略浏览器警告继续登录。
4. 某个地址无法访问时，可尝试入口清单中的其他地址。多个域名可能连接同一服务，不代表独立节点或不同账号体系。
5. 一次失败只记录为“本次无法确认”，不要据此宣称服务已经停止或永久失效。

## 页面能打开，但账号操作遇到问题

分别记录入口域名、点击的按钮、最终页面和错误提示。已有账号应选择登录选项；忘记密码时使用页面提供的找回流程，不要把账号或密码贴进公开反馈。

如果页面反复跳转、显示错误或找不到预期功能，可通过账户页面的支持渠道反馈。魔戒机场官方维护人员会结合入口地址、操作步骤、最终页面和错误提示核查。

## 网页可用，客户端不可用

先检查订阅是否过期、剩余流量、客户端所用配置与服务方最新说明。客户端节点的可用性与网站入口不是同一指标。需要联系客服时，通过确认的服务渠道提供必要信息，不把订阅密钥发到公开讨论区。

## 如何阅读一次链接检查报告

| 报告字段 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| checkedAt | 该次请求的时间，ISO 时间以 Z 表示 UTC | 全天持续在线 |
| httpStatus | HTTP 响应状态 | 登录、付款或代理节点一定正常 |
| finalUrl、redirects | 这次请求的跳转路径 | 注册、登录及付款等所有按钮的跳转 |
| titleMentionsBrand | 标题是否包含魔戒或 Mojie | 网站所有功能均正常 |
| page_observed | 当次返回页面且标题含品牌名 | 已完成登录或节点测试 |
| review_needed、unverified、http_error | 需要人工复核、未能确认或发生 HTTP 错误 | 一定属于假站或已经停运 |

HTTP 403 可能是站点针对该客户端的访问限制，也不能单独说明其他用户打不开。记录原结果，并在允许访问的浏览器中人工查看即可；不要频繁重试、绕过验证码或使用登录凭据做自动探测。
