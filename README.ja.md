## Mojie のサイトが開かない場合

| 状況 | 最初に確認すること | 判断できること |
| --- | --- | --- |
| タイムアウトや DNS エラー | ドメインと時刻を記録し、ほかのサイトが開くか確認する | 現在の環境では接続できていないが、サービス終了とは断定できない |
| 証明書や安全でない接続の警告 | アカウント情報の入力を止め、ドメインと端末の時刻を確認する | 証明書や接続の問題を解決してからログインする。警告を無視しない |
| ページは開くが既存アカウントを使えない | 入力内容、ログインページ、エラーを確認し、アカウントページのサポートへ連絡する | サイトへの接続とアカウントへのログインは別の段階 |
| サイトは正常だがクライアントが使えない | サブスクリプションの有効性、残りデータ量、クライアント設定を確認する | サイトとプロキシノードは分けて確認する必要がある |
| ページごとに料金や条件が違う | アカウントページで現在のプラン、有効期限、サポート条件を確認する | 購入・更新前に現在の条件を確認する必要がある |

問い合わせには、ドメイン、北京時間での発生時刻、操作手順、エラー、最終的なページのアドレスを記載してください。パスワード、支払情報、サブスクリプション URL は公開しないでください。

## プランとクライアントの確認事項

アカウントページで、次の項目を比較してください。

- **料金とデータ量：** 月額制かデータ量に応じた課金か、データの有効期限、チャージとプラン購入が別の操作かどうか。
- **端末の制限：** 利用可能な端末数や同時接続数、お使いのスマートフォン、パソコン、クライアントへの対応。
- **利用時の性能：** 環境の記載がない速度画像よりも、同じ地域、通信事業者、時間帯での結果を参考にしてください。
- **サポート：** 問い合わせ先、返金条件、障害時の通知方法が明確かどうか。

クライアントは、確認できるサービス側の案内、またはクライアント自身の公式配布先から入手してください。サブスクリプション URL には個人の認証情報が含まれる場合があるため、公開 Issue や画像に載せないでください。

## よくある質問

### Mojie の最新の公式サイトアドレスはどこにありますか？

上の一覧を参照してください。アドレスの更新日は文書の冒頭に記載しています。リンクを開くか、アクセスページをブックマークしてください。接続できないドメインがある場合は、別のアドレスを試せます。

### 既存アカウントでのログインや問い合わせはどうすればよいですか？

サイトを開いてログインを選び、既存アカウントを使用してください。エラーが出た場合は内容、ドメイン、時刻を記録し、アカウントページのサポートへ連絡してください。パスワード、支払情報、サブスクリプション URL を公開 Issue に送らないでください。

### サイトのアドレス、サブスクリプション URL、ノードの違いは何ですか？

サイトはサービス情報の閲覧やアカウント管理に使用します。サブスクリプション URL はクライアントが設定を取得するためのもので、個人キーを含む場合があります。ノードはクライアントが実際に接続するネットワークサービスです。サイトが正常でも、ノードの利用可否や速度テストの実施を示すものではありません。

### 複数のドメインがあれば独立した予備経路が保証されますか？

いいえ。あるドメインが使えない場合にほかの入口を試せますが、同じサイトにつながる場合があります。独立性や、異なるノード・より高速な経路を保証するものではありません。

### Mojie のプラン料金やキャンペーンはどこで確認できますか？

アカウントページで現在のプラン、料金、適用条件を確認してください。購入前にデータの有効期限、端末制限、返金条件を確認し、更新前にも条件の変更を確認してください。実際の性能は地域、通信事業者、時間帯にも左右されます。

### アドレス更新日は自動で変わりますか？

いいえ。アドレス一覧を更新したときに変更します。一般的な文章の編集やページの再生成では、自動更新されません。
